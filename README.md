# وحدة الصقر · Falcon Unit

لعبة أكشن تكتيكية لوحدة شرطة خاصة في عمّان — مبنية بمحرك Godot 4.3 لأجهزة أندرويد.

**المهمة:** سطو مسلّح على «مصرف الشرق» في جبل عمّان. قُد سيارة الوحدة عبر شوارع المدينة إلى الطوق الأمني، فجّر الباب، حرّر الرهائن واعتقل المسلحين.

- اختر عدد أفراد فريقك (0–4) والصعوبة
- قيادة حقيقية بفيزياء تعليق وعجلات، صفارة وأضواء
- حركة مرور في الشوارع، تاكسي أصفر، محلات بلافتات عربية، خزانات مياه وسخانات شمسية على الأسطح
- اقتحام بعبوة، تصوير بطيء، أوامر استسلام وتكبيل

## تحميل اللعبة على الجوال
افتح صفحة **Releases** في المستودع وحمّل `falcon-unit.apk` من أحدث إصدار، ثم ثبّته (اسمح بالتثبيت من مصادر غير معروفة).
كل تعديل يُرفع على فرع `main` يبني APK جديد تلقائياً عبر GitHub Actions.

## التحكم
| الكمبيوتر | الجوال |
|---|---|
| WASD حركة/قيادة · الفأرة نظر | عصا يسار للحركة · سحب يمين للنظر |
| زر الفأرة الأيسر إطلاق · الأيمن تصويب | أزرار نار / تصويب |
| F ركوب/نزول · E تفاعل · Q أمر استسلام · R تعبئة · H صفارة · Space فرامل/قفز | أزرار على الشاشة |
