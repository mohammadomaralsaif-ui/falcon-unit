# Voice lines

Every line is spoken in **English** by its own character voice; the HUD shows the **Arabic** text as the subtitle.

Generated by `tools/build_voices.py` with offline neural TTS (sherpa-onnx + Piper English voices).
`tools/voice_en.json` maps each Arabic line (the subtitle) to the English sentence that is spoken;
the cast (which Piper voice plays which character) is the `CAST` table in the script.

File name = md5("<speaker>|<Arabic subtitle text>"). Re-run the script after changing any dialogue text
(add the English version of a new line to `tools/voice_en.json` first).
To use real recorded voices instead, replace the .ogg files keeping the same names.

Licences differ per Piper voice (see each voice's MODEL_CARD in the Piper voices repository) —
check them before any commercial release.
